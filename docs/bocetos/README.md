# Bocetos

Bocetos aprobados de Kasa. Cada uno es la app real con los cambios propuestos, capturada con `herramientas/boceto.py` a 1080 px de ancho; su código está en la rama de la versión, en un commit «B-xx: …». Las reglas están en [CONTRIBUTING.md](../../CONTRIBUTING.md#bocetos).

Desde B-02, las pantallas que se desplazan se capturan enteras, de arriba abajo (`--entera`), como la captura desplazada del teléfono. El progreso de ejemplo que no se puede escribir en la línea de comandos (palabras propias, estadísticas) va en un archivo junto a las imágenes, como [B-02.json](B-02.json).
